# The Growth Exponent

The Growth Exponent is a public website for a growth engineering and digital platforms business. The source repository is private.

## Stack and delivery

- Next.js and React
- Tailwind CSS
- Analytics and CRM integrations
- Static-site deployment

The work focuses on a public-facing site for founders, operators, and CTOs, with automation and scalable systems as the subject of the business site.
