# ZMM 2.0

[Repository: impascoe/zmm-2.0](https://github.com/impascoe/zmm-2.0)

ZMM 2.0 is an archived personal C compiler written in Zig for educational use.

## Scope

- Lexical analysis
- Syntax parsing
- x86-64 assembly output

The project records an earlier compiler-design exercise and remains available as an archive.
