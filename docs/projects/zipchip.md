# ZipChip

[Repository: impascoe/ZipChip](https://github.com/impascoe/ZipChip)

A CHIP-8 emulator written in Zig.

## Implemented areas

- Video rendering
- Audio
- Timing
- Input controls
- CHIP-8 opcode implementation

ZipChip combines emulator development with graphics, audio, timing, and input handling in Zig.
