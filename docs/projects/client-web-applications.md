# Client web applications

## Online will-producing website

A collaborative web application for creating legal wills online.

### Technology

- React front end
- Go API development
- Database integration
- User authentication

### Functional scope

The application includes document generation, secure data handling, a user-facing interface, and work related to legal-compliance requirements.

## Donation-tracking application

A web application for tracking donations to Australian charitable organisations.

### Technology

- Python API development
- NoSQL database
- Web front end
- Data visualisation

### Functional scope

The application covers donation analytics, organisation profiles, reporting, and user-account management.
